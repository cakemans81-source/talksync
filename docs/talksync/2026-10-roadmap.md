0. 문서 목적·사용법
--------------------------------------------------------------------------------
이 문서는 2026-10-02에 제품 오너가 승인한 로드맵이다.
다음 3~6개월의 1차 목표는 "실사용자 검증 먼저"이며,
공개 베타(v0.2.0)까지의 마일스톤·일정, 무료 로컬 엔진과 유료 Gemini
업그레이드 설계, 리스크, 법률 체크리스트, 베타 이후 단계를 정리한다.

사용법:
- 일정·범위·판정 기준은 이 문서를 기준으로 한다.
- MASTER_CONTEXT는 제품 원칙·기술 기준의 상위 문서이고,
  이 문서는 그 위에서 "무엇을 언제 하는가"를 정한다.
  MASTER_CONTEXT 13장(출시 및 개발 순서)은 이 문서를 가리킨다.
- 표시 규칙: "(시안)" = 확정 전 가정값, "(추정)" = 측정 전 추정,
  "(미검증)" = 에이전트 조사 보고로 직접 검증하지 않은 값,
  "(확인 필요)" = 구현 직전 공식 출처 재확인 대상.
- 모델 가격, API 상태, 라이선스, 드라이버 정책은 시점에 따라 바뀐다.
  실제 구현 직전에 공식 출처로 재확인한다.
- 이 문서는 자동 구현 명령이 아니다. DB·결제·Auth·드라이버·서명·삭제
  작업은 MASTER_CONTEXT 15~16장에 따라 별도 고위험 티켓으로 분리하고,
  EV PIN·HDC 제출 등 사람 승인 게이트는 자동 실행하지 않는다.

1.1 제품·범위 결정
--------------------------------------------------------------------------------
- 1차 목표 (3~6개월): 실사용자 검증 먼저
- 핵심 사용자: 웹 화상회의 참여자 (Google Meet / Teams / Zoom 웹)
- 베타 범위: Rx(상대 음성 -> 내 언어 자막/음성)만.
  Tx(내 음성 송출)는 드라이버 서명 후.
- 공개 베타 목표: 약 6~8주 후 (2026-11-23 ~ 11-27)
- 언어: 다국어 양방향(글로벌). 무료 엔진은 언어 등급제로 노출.
- 로드맵 접근: A안 "무료·유료 동시 베타" (M1 2주차 무료 엔진 Go/No-Go 판정)

1.2 과금·상품 결정
--------------------------------------------------------------------------------
- 무료: 사용자 PC 로컬 오픈소스 엔진 (API 키 불필요)
- 유료: 회사가 Gemini API 비용을 부담하고 사용자에게 사용량 과금
  (충전식 크레딧)
- 사용자 Gemini API 키(BYOK)는 진입 장벽이므로 기본 경로에서 제외.
  개발자 플래그로만 유지.
- 가입 시 업그레이드 체험 10분 무료: 승인
- 잔액 0 -> 끊김 없이 무료 엔진 자동 복귀(+충전 안내): 승인

1.3 기술 결정
--------------------------------------------------------------------------------
- 무료 엔진 실행 위치: 사용자 PC 로컬
- 엔진 프로세스 구조: (a) Electron utilityProcess + Node 네이티브 애드온
  (sherpa-onnx-node, node-llama-cpp)
- 대안 (b) 네이티브 sidecar 실행 파일(C++/Rust)은 M1에서 (a)가 막힐 때만

1.4 일정·운영 결정

  (사람 승인 게이트: EV 토큰 PIN, HDC 제출)

3. 무료 로컬 엔진 아키텍처

3.1 프로세스 구조
--------------------------------------------------------------------------------
Electron utilityProcess + sherpa-onnx-node(ASR) + node-llama-cpp(MT,
Windows CPU/Vulkan/CUDA 프리빌드).
- 메인 프로세스와 분리, 크래시 격리, 자동 재시작
- 대안 (b) 네이티브 sidecar 실행 파일(C++/Rust): M1에서 (a)가 막힐 때

3.2 데이터 흐름
--------------------------------------------------------------------------------
탭 오디오 (useBrowserTabAudioCapture)
 -> AudioWorklet 16kHz PCM16
 -> MessagePort (렌더러 -> 엔진 직결, 로컬 포트 노출 없음)
 -> 스트리밍 ASR (부분 원문)
 -> 문장 확정 (ASR 끝점 / 침묵 >= 0.5초 / 최대 8초)
 -> 확정 구간만 MT (토큰 스트리밍, 직전 1~2문장 문맥)
 -> 자막 이벤트 { 원문 부분/확정, 번역 처리 중/확정, 지연 ms }
 -> 렌더러 자막 UI

3.3 엔진 추상화
--------------------------------------------------------------------------------
TranslationEngine { start, pushAudio, onSubtitle, stop, status, usage }
- LocalEngine (무료)
- GeminiManagedEngine (유료)
- 업그레이드 버튼 = 같은 오디오 소스에서 엔진 교체

3.4 모델 배포
--------------------------------------------------------------------------------
- 첫 실행 다운로드: ASR ~650MB + MT Q4 ~1.5GB = 약 2GB
  (언어 등급별로 필요한 것만)
- 저장 위치: %LOCALAPPDATA%\TalkSync\models
- 서명된 매니페스트 (URL, SHA256, 라이선스)
- 이어받기·진행률
- CDN (Cloudflare R2 등). GitHub Releases는 파일당 2GB 제한
- 라이선스 고지 표시

5) 4분쯤 다음 5분치 토큰 미리 발급 (sessionResumption으로 무중단)
6) 종료 시 서버 시각 기준 실제 사용 1분 단위 과금, 나머지 환불

10.6 드라이버 서명 사실 (확정)
--------------------------------------------------------------------------------
- Windows 10 1607+ Secure Boot 환경에서 신규 커널 드라이버는
  Microsoft 서명이 필수다.
- EV 인증서 단독 서명은 로드 불가다
  (2015-07 이전 크로스서명 예외는 폐지).
- EV는 HDC 계정 신원 확인과 제출 CAB 서명용이다.
- 경로: M0는 Attestation 서명(HLK 불필요, Win10/11 클라이언트,
  Server 불가) — Code 52 해소·내부 테스트용. 공개 배포 경로(HLK/WHCP
  포함)는 R10에 따라 M2까지 결정.
- testsigning 모드는 개발용이며 배포 불가다.
- 정정 (2026-10-02 Microsoft Learn 직접 확인; driver-signing-offerings,
  ms.date 2026-03-23): Microsoft는 해당 절을 "Attestation signed drivers
  for testing scenarios"로 표기하고 "For testing purposes only"로
  안내한다. 요구사항 표상 Windows 10+는 Attestation 서명 드라이버를
  신뢰하지만, 프로덕션에는 HLK 테스트를 거친 대시보드 서명(WHCP)을
  권장하며, Attestation 서명 드라이버는 Windows Update 리테일 배포가
  불가하다. 따라서 M0 Attestation은 Code 52 해소·내부 테스트용
  이고, 일반 공개 배포 경로는 별도 결정이 필요하다 (R10).
- 현재 상태 (MASTER_CONTEXT 13장·17장): signer는 WDKTestCert(개발용),
  Code 52 미해소, EV signing·HDC 제출 미수행.
